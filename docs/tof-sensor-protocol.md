# VL53L8CX 센서 테스트 프로토콜

XIAO ESP32-S3 Sense는 USB CDC로 줄바꿈이 포함된 UTF-8 JSON을 전송한다. 기존 `left_mm`/`right_mm` 형식은 그대로 사용할 수 있고, 64존 원본을 보낼 때는 다음 형식을 사용한다.

```json
{"left_zones_mm":[500,510,505],"right_zones_mm":[1200,1180,1210]}
```

각 배열에는 유효한 1~100000mm 정수만 넣는다. Android 앱은 각 배열의 최솟값을 해당 방향의 대표 거리로 사용한다. 배열이 비어 있거나 유효한 값이 없으면 그 프레임을 무시한다.

두 VL53L8CX는 SDA(D4), SCL(D5), 3V3, GND를 공유한다. LP_A는 D2, LP_B는 D3에 연결한다. 센서의 SPI/I2C 핀은 각 센서의 GND에 연결해 I2C 모드를 선택한다. 부팅 때 두 LP를 LOW로 둔 뒤 A, B를 순서대로 깨우고 서로 다른 I2C 주소를 지정한다.

주소 표기(7비트/8비트)와 초기화 함수는 사용하는 VL53L8CX Arduino 라이브러리 예제에 맞춰 확인한다. 센서 두 개가 안정적으로 읽힌 뒤에만 위험도 판단과 공간음향 계층을 연결한다.
